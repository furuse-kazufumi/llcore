# M2.0 smoke — 会話連結性教師 × cert gate の最小実証 (2026-06-12)

> 設計 = `docs/M2_CERT_CONNECTIVITY_DESIGN_2026_06_12.md`。正本データ =
> `out/m2_connectivity_poc.json`、スクリプト = `m2_connectivity_poc.py` (v4)。
> 本測定 (M2.1, 4 gate × 15 seed) は `m2_gate_comparison.py` — 事前登録済み・実走中。

## 一行要約

実会話 35 turns の**ターン境界予測 (T1)** は SmolLM2 hidden 上で学習可能な信号であり
(全 seed で CE が floor を下回る)、同時に**無 gate 進化は採用 gene の ~92% が真に発散
(ρ≥1)**、cert_inf gate は **false-admit 0 のまま学習を成立させる** (capability tax
+0.01〜0.04) — 「学習できる × 安全を選ばない」が 1 つの smoke で同時観測された。

## 数値 (3 seed × 2 gate, budget 2000, MiniLM… ではなく SmolLM2-135M layer15)

| seed | gate | train CE (floor) | held-out CE (floor) | archive | ρ≥1 / archive | rho_max |
|---|---|---|---|---|---|---|
| 0 | none | **0.5186** (0.6269) | 0.4386 (0.5495) | 65 | 61 (94%) | 2.821 |
| 0 | cert_inf | 0.5536 | 0.4875 | 28 | **0** | 0.993 |
| 1 | none | **0.4730** (0.6301) | 0.5118 (0.5482) | 67 | 61 (91%) | 2.818 |
| 1 | cert_inf | 0.5580 | **0.4892** | 37 | **0** | 0.997 |
| 2 | none | **0.5494** (0.6260) | 0.4800 (0.5591) | 61 | 56 (92%) | 2.862 |
| 2 | cert_inf | 0.5647 | 0.4842 | 43 | **0** | 0.998 |

- smoke 判定: **識別力 = True** (全 seed train CE < floor − 0.02) /
  **sound gate false-admit 0 = True**。209 秒で完走。
- seed 1 では cert_inf の held-out (0.4892) が none (0.5118) を**上回る** —
  gate の正則化効果の徴候 (3 seed では結論しない。M2.1 の C2 で見る)。
- cert_inf 採用 gene の rho_max は 0.993-0.998 — 境界ぎりぎりまで攻めて 1 を
  超えない。**保守的な inf ノルム証明の admit 領域内で、進化は境界近傍 (最も
  表現力のある領域) を見つけている**。

## smoke が踏んだ罠と修正 (経緯の保全 — それ自体が知見)

1. **readout v1 の表現力欠陥**: X 空間 centroid + 分離 β は定数予測 (クラス事前)
   を表現できず、最適化後も train CE 0.9022 > floor 0.6269。
   → v2: s 空間 LDA centroid + within-class β + **log-prior bias** (floor 包含を
   構造的に保証 — 自明 gene で CE = floor 厳密一致を検証)。
2. **cert_sdp の resample 停滞**: 探索分布の ~94% が発散側 → ほぼ全 reject →
   SDP solve (数百 ms) × 数千回 = smoke 不適。→ smoke は cert_inf (µs, 同 sound)。
3. **cert_inf の空転**: random init の admit = 実測 **0/200** → archive が
   立ち上がらない。→ **W→0 反復縮小 fallback** (W=0 は必ず admit, 実測 200/200)
   — evolve() の known-safe fallback 規律の MAP-Elites 移植漏れだった。

## honest 留保

- empirical_rho は from-below オラクル: 「ρ≥1 検出」は確実、「<1」側は near-boundary
  の見逃しがありうる。cert_inf admit の rho_max 0.998 は「下界が 0.998」の意味。
- 3 seed の smoke — 統計主張はしない。本判定は M2.1 (15 seed, 事前登録
  G1/G2/C1/C2) で行う。
- T1 の held-out floor は「train prior の定数予測を held-out に適用した CE」で
  定義 (held-out 自身のエントロピーではない — 定数予測器は train でしか fit
  できないため)。
- 縮小 fallback は gate が探索を W 縮小方向へ誘導するバイアスを持つ (gated 進化の
  挙動として明示的に受け入れ、ドキュメント化)。
