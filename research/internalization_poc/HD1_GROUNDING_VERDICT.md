## H1 の意味 — 「sound ≫ empirical」の gradient 基質接地

toy (viability thread) で確立した「sound 予見 ≫ empirical 観察」の階層が、実モデル
(GatedRecurrentLM, d=96, grad 400 steps, tiny-shakespeare) の gradient 訓練でも成立した:

- **NONE**: 窓契約死率 0.476 → 0.778 → 0.961 (n=64/128/256)。drift は n とともに激化、
  final rho (高精度) は n=256 で **1.969 ≈ HD-1 §7 の ρ→1.95 帯を再現** (E3 接地サニティ)。
- **OBSERVE_P2** (proxy 閾値回避 + 死履歴 16 seeds 共有): 0.216 / 0.646 / 0.745 —
  **NONE より一貫して低いが、ENDO (全 n で 0.0) には遠く及ばない**。
- **アーティファクト規律 (binding)**: 連続量 2 指標 (窓内 max rho / ρ 超過積分) も全 n で
  OBS_P2 < NONE — 特に ρ 超過積分は n=256 で **72.6 → 19.0**。回避は「死亡測定点を消す」
  計数効果ではなく、ρ≥1 曝露そのものを減らしている。よって解釈は事前登録どおり
  **「empirical 観察は部分的死回避を提供するが sound に届かない」を採用**。

## H2 の honest 報告

REVIVE (死後修復) の最終 CE は ENDO (rollback) より全 3 n で低い (median Δ = −0.074 /
−0.080 / −0.182) が、n=128 の p=0.0577 > 0.05 により事前登録の連言条件を満たさない →
**「検出せず」を報告 (盛らない)**。事前登録 §5 のとおり「toy 固有 or 16 seeds で検出不能」の
区別はつけない。方向の全 n 一致と n=256 の p=9.2e-5 は**記述的事実としてのみ**記す
(post-hoc の救済はしない)。将来 32 seeds での再走が自然な次手 (新規登録が必要)。

## Exploratory 所見 (補正外, 記述)

- **E8 (最重要の機構所見)**: 効くのは**死履歴の共有**。OBSERVE_P1 (自己履歴のみ) は
  0.449 / 0.939 / 0.910 と NONE 同等〜悪化 (n=128 では NONE 0.778 より**悪い**)。
  P2 (16 seeds の死を pool) で初めて回避が成立。toy の「他個体の死から学ぶ」(OBSERVE
  社会的観察) の gradient 版は **2-pass 共有があって初めて機能する**。
- **E10**: 回避の即効性 (avoid 直後測定点が非死) は n=64: 76% → n=128/256: 3% に崩壊。
  大 n では β=0.5 縮小が drift 速度に追いつかない — それでも曝露積分は減る (慢性的に
  押し返し続ける)。empirical 回避の限界形が見えた。
- **E11**: n=128/256 では補集合窓 (NONE 平均 ρ<1 の測定点) の死は両 arm とも 0 —
  効果は excursion 窓内の差。n=64 では補集合でも OBS_P2 0.018 < NONE 0.096。
- **E1**: NONE arm 内で死亡率×CE は正相関 (n=128: +0.89, n=256: +0.58) = 死ぬ seed ほど
  CE も悪い。「死は性能と引き換えの自由」ではない (decoupling は観測されず)。
- **E2**: 契約死フラグ × sep_rate の Spearman = +0.62 / +0.80 / +0.79 (全 n ≥ 0.5) →
  事前登録分岐どおり**契約死を実害 proxy として採用** (D1 妥当性確認)。
- **E3**: ENDO−NONE の CE コスト = +0.127 / +0.156 / +0.076 (HD-1 帯 0.03–0.12 と概ね整合、
  n=128 のみ僅か上振れ; init protocol 差の注記は prereg §4 参照)。
- **E9**: ENDO_K8 (k=8) の CE 2.1227 ≈ ENDO (k=4) 2.1232 — k 感度は小 (H2 の従属所見
  懸念は実測上小さい)。
- 検出力の自白 (prereg §3) との照合: H1 は均一寄りの効果だったため検出できた。H2 は
  効果量が n 依存 (Δ −0.07→−0.18) で、16 seeds では n=128 を拾えなかった — 事前の
  「異質効果で急落」warning の現実化。

## 結論 (1 行)

**監督の階層 (sound 継続監督 ≫ empirical 共有観察 ≫ 自己観察 ≈ 無監督) が gradient 基質で
confirmatory に確立。修復 vs rollback の CE 優位は方向一貫だが規則上「検出せず」。**
