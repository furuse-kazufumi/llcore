# llcore 進化研究 用語集（平易版・図入り）

この研究で使う英語・専門用語を「山登り」のたとえで説明します。
※「**③**」= 進化4要素の3番目「**適者生存（良いものだけ選ばれて残る）**」のこと。

---

## まず全体像 ── 「設計探し」は「山登り」

設計の良し悪しを **地形の高さ** で表します。**高い場所 = 良い設計**。一番高い頂上（最良の設計）を探すゲームです。

### 地形その1：滑らかな一つ山（簡単）

```
 良さ↑
  高 |            ___________
     |         __/           \__
     |      __/                 \__     ← どこから登っても
     |   __/                       \__     同じ頂上に着く
  低 |__/                             \__
     +----------------------------------→ 設計の選び方
         → 普通の「山登り法」で十分。凝った工夫は不要。
```

### 地形その2：だまし地形（難しい＝欺瞞的）

```
 良さ↑                                  /\
     |                                 /  \   ← 本物の頂上（高い）
     |        ニセ頂上                /    \
  中 |         /\         谷         /      \
     |        /  \______________/        \
  低 |____/                                  \
     +----------------------------------------→ 設計の選び方
          ↑ニセ頂上で素朴な山登りは停止（谷を下れない）
          → 「多様性を保つ探索」だけが谷を飛び石で渡れる
```

**今回の研究の核心**：適者生存（③）が本当に役立つのは **「だまし地形」のときだけ**。
滑らかな一つ山では、普通の山登りで十分なので③は要らない。

---

## 探し方（探索アルゴリズム）の比較図

```
【だまし地形での各手法の動き】

  山登り法        :  ニセ頂上まで登る → 谷を下れず停止 ✗
  ランダム探索    :  あちこち試すが本物の頂上にはまず当たらない ✗
  多様性を保つ探索:  ニセ頂上・谷・途中…いろんなタイプを保管
                     → 谷を「飛び石」で渡り本物の頂上へ到達 ✓
```

## 用語表

### A. 進化のことば

| 英語 | 日本語 | かみ砕くと |
|---|---|---|
| evolution | 進化 | 良い設計が生き残り少しずつ改良される仕組み（生物進化と同じ発想） |
| gene | 遺伝子 | 設計の中身を表す数値の並び（＝設計図） |
| fitness | 適応度 | その設計の良さ（＝地形の高さ・性能スコア） |
| population | 集団 | 同時に試している設計の集まり |
| **selection（③）** | 選択・適者生存 | 良い設計だけ選んで残すこと。**「③」はこれ** |
| variation | 変異 | 設計を少しランダムに変える |
| heredity | 遺伝 | 親の設計が子に引き継がれる |

### B. 探し方（探索アルゴリズム）

| 英語 | 日本語 | かみ砕くと |
|---|---|---|
| landscape | 地形 | 設計の良し悪しを地形の高さで表した図 |
| hill-climbing | 山登り法 | 今より少し良い方へ動くだけの素朴な探索 |
| random search | ランダム探索 | でたらめに大量に試して一番良いのを選ぶ |
| random-restart | ランダム再出発 | 山登りで詰まったら別の場所から再挑戦 |
| **MAP-Elites** | マップエリート | いろんなタイプを満遍なくキープする探索（多様性重視） |
| niching | ニッチ化（多様性維持） | 「違うタイプ」の設計を捨てずに残す工夫 |
| panmictic GA | 普通の遺伝的アルゴリズム | 多様性を特に保たない素朴な進化探索 |
| baseline | 基準（比較対象） | 「これに勝てるか？」の比べる相手 |
| evaluation budget | 評価予算 | 試せる回数の上限（公平に比べるため全手法同じにする） |

### C. 地形の種類・状態

| 英語 | 日本語 | かみ砕くと |
|---|---|---|
| unimodal | 単峰 | 山が一つだけ（簡単） |
| multimodal | 多峰 | 山が複数（難しい） |
| local optimum | 局所最適 | ニセの頂上（そこそこ高いが本物でない） |
| global optimum | 大域最適 | 本物の頂上（一番高い） |
| deceptive | 欺瞞的（だまし） | ニセ頂上に引っかかり本物へ行けない地形 |
| valley | 谷 | 本物の頂上の手前にある低い所 |
| plateau | 連結した高台 | 高い所が一枚につながっている（峰が分かれていない） |
| corridor | 通り道 | 本物の頂上に至る細い経路 |

### D. 今回の実験道具

| 英語 | 日本語 | かみ砕くと |
|---|---|---|
| ESN (Echo State Network) | エコーステートネットワーク | 中身を固定した超軽量AIモデル。CPUで速い |
| reservoir | リザバー | ESNの「固定した脳みそ」部分 |
| ridge readout | リッジ読み出し | 脳みその状態から答えを読む簡単な計算（一発で解ける） |
| corpus | コーパス | 学習に使う文章データ（今回は本物のソースコード） |
| next-char prediction | 次の文字予測 | 「次に来る文字」を当てるAIの基本課題の縮小版 |

### E. 結果・判定のことば

| 英語 | 日本語 | かみ砕くと |
|---|---|---|
| seed | シード | 乱数の初期値。条件を変えて再現性を確認するために何種類も使う |
| p-value | p値 | 「偶然でこうなる確率」。小さい（<0.05）ほど本物の差 |
| Cliff's delta | クリフのデルタ | 差の大きさ。+1で圧勝、0で互角、−で負け |
| honest re-evaluation | 公正な再評価 | 結果を水増ししないため別の乱数で測り直すこと |

## これまでの結論（この地図でいうと）

1. **だまし地形を作ったら** → 多様性探索（③）だけが本物の頂上に到達、普通の探索は全部ニセ頂上で停止。
   → **③は「だまし地形」でなら本当に効くと実証**。
2. **滑らかな地形では** → ③の優位は消えた（普通の山登りでも頂上に着くから）。
3. **実問題に近いミニAIの地形を測ったら（最新）** → **滑らかな一つ山だった**。
   多様性探索は普通の探索に勝てず。→ **実問題では「だまし地形」が自然には現れない兆候**。
